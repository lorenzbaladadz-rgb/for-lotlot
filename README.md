# For Lottie 💌

A hand-written letter that types itself out.

## Add your song
Drop your music file in as `assets/song.mp3` and it will play automatically
when the envelope is opened (with a mute button in the corner). The page works
silently without it too.

## Optional photo
Drop a picture in as `assets/photo.jpg` and it will stay hidden until the
signature finishes, then fade in with a slow drift and the caption "you & me".

## Deploy on GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repo: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Wait a minute, then visit `https://<username>.github.io/<repo>/`.
